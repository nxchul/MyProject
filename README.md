## 🎯 제품 개요

### 비전
YNS TSMC Design House Platform은 반도체 설계 고객들에게 AI 기반 지능형 서비스를 제공하는 차세대 디지털 플랫폼입니다. TSMC 파운드리 서비스의 복잡한 프로세스를 단순화하고, 실시간 AI 상담을 통해 고객 경험을 혁신적으로 개선합니다.

### 미션
- 반도체 설계 프로세스의 디지털 전환을 선도
- AI 기술을 활용한 24/7 실시간 고객 지원 제공
- MPW(Multi-Project Wafer) 서비스 접근성 향상
- 설계부터 생산까지 원스톱 솔루션 제공

### 핵심 가치
1. **접근성**: 언제 어디서나 접근 가능한 클라우드 기반 서비스
2. **효율성**: AI를 통한 즉각적인 답변과 자동화된 프로세스
3. **전문성**: TSMC 공정에 특화된 깊이 있는 기술 지원
4. **보안성**: 엔터프라이즈급 보안과 NDA 관리

```
프로젝트 생성 → GDS 업로드 → DRC 체크 → 정보 입력 → 검토 → 제출
```
